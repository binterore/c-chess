# 将·界 · 3D 中国象棋

一款打开浏览器即可对弈的 3D 中国象棋游戏。古战场沙盘、拟人化战阵棋子、专属走子与吃子演出、传统中式棋谱、本地 AI、三十道残局以及好友房间对战，共同组成完整的单机与联机体验。

## 玩法

- **人机演武**：选择红方或黑方，并在入门、棋手、国手三档棋力之间切换。AI 在 Web Worker 中运行，推演时不会阻塞棋盘交互。
- **残局破阵**：三十道经过验证的一手绝杀残局，分为五卷。提供目标提示、进度记录与连续挑战。
- **好友论道**：生成六位房间码与邀请链接，服务端校验座位、回合和着法合法性，支持断线重连、认输、议和、悔棋申请与快捷传讯。
- **同屏对弈**：一屏两席，红黑双方轮流落子。
- **经典棋面**：在战阵棋子与传统大字棋子之间即时切换。

## 操作

- 点击棋子选中，绿色圆点表示空位，红色圆环表示可吃棋子。
- 拖动棋盘旋转视角，滚轮或双指缩放。
- 桌面端右侧棋谱面板显示着法、吃子与引擎信息。
- 移动端通过底部操作栏落子、悔棋、认输和打开棋谱。

## 规则覆盖

规则引擎覆盖中国象棋全部基础走法，包括：

- 将帅九宫移动与照面限制
- 士斜行、象走田与塞象眼
- 马走日与蹩马腿
- 车直行、炮隔子吃
- 兵卒过河横走且不可后退
- 送将过滤、将军、将死与困毙
- 三次重复局面及长将判负
- 传统中式记谱、认输、超时与和棋

## 技术架构

- **前端**：React 19、TypeScript、Vite、Three.js
- **3D 表现**：程序化低多边形棋子、动态棋面纹理、粒子对象池、光晕与镜头演出
- **规则引擎**：纯 TypeScript 模块，与渲染层完全解耦
- **AI**：Web Worker 内运行 Negamax + Alpha-Beta + 静默搜索 + 置换表
- **联机**：Express 5 + Socket.IO，服务端权威校验与房间重连
- **音效**：Web Audio API 实时合成
- **离线**：生产构建注册 Service Worker，人机与残局模式可离线使用

## 本地运行

要求 Node.js 22 或更高版本。

```bash
pnpm install
pnpm dev
```

访问 `http://localhost:5173`。开发模式会同时启动 Vite 前端与 `3001` 端口联机服务。

## 验证

```bash
pnpm typecheck
pnpm test
pnpm build
```

测试覆盖初始局面合法着法、马腿、象眼、炮架、兵卒过河、将帅照面、困毙、传统记谱、三次重复、AI 合法着法，以及全部三十道残局的将死解法。

联机服务启动后，可再执行一次双客户端房间烟雾测试：

```bash
pnpm verify:online
```

## 生产运行

```bash
pnpm build
pnpm start
```

默认由 `3001` 端口同时提供静态前端、Socket.IO 联机服务与 Service Worker 资源。可通过 `PORT` 环境变量覆盖端口。
