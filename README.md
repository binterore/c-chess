# 中国象棋在线对战 · Chinese Chess Online

古风国韵与现代粒子光效相结合的在线中国象棋对战平台。支持好友实时联机对战、炫酷杀棋特效（卧槽马、重炮轰鸣、挂角马、铁门栓等）、行棋轨迹波纹、绝杀大捷全屏庆典以及单机人机演练与本地同屏双人对战。

## 功能亮点

### 1. 炫酷技能与杀棋特效系统
- **卧槽马**：伏槽良驹穿心跃，触发金红烈焰天马跨屏奔腾、烈焰冲击波与全屏金色书法战帖。
- **重炮轰鸣**：双炮连环蓄力，发射高能离子激光穿透炮架直轰敌将中宫，引发等离子爆炸与震屏烟雾。
- **挂角马 / 铁门栓 / 抽将抽车 / 自毙闷杀**：检测特定象棋经典杀法并触发独属视觉效果与诗韵横幅。
- **走棋与吃子特效**：每步走棋伴随金色丝帛拖尾轨迹与落子冲击光圈；吃子触发墨色激荡与金芒碎屑。
- **全屏绝杀与胜负庆典**：绝杀将死触发胜利号角音效、双侧五彩礼花喷射及大捷勋章。

### 2. 独立 Web Audio 音效引擎
- 无需依赖外部音频文件，采用纯浏览器 Web Audio API 实时合成：
  - 沉稳木质落子敲击声
  - 裂金碎石吃子斩杀声
  - 浑厚青铜编钟古刹将军鸣响
  - 卧槽马天马长嘶与铁蹄轰鸣
  - 重炮双管轰炸低音炮冲击波
  - 胜利大捷庆典三和弦

### 3. 多元对弈模式
- **好友联机对战**：
  - 一键创建房间，生成 6 位专属房间号。
  - 支持一键复制专属邀请链接（含 `?room=XXXXXX`），好友点击即可秒入。
  - 阵营选择（红方先手、黑方后手、随机分配）。
  - 多档包干计时（超快棋 3 分钟、快棋 5 分钟、标准 10 分钟、慢棋 20 分钟或不限时）。
  - 支持无人数限制好友旁观（Spectator Mode）。
  - 局内互动功能：悔棋申请与确认、提和协商、认输、再来一局、快捷战术用语互动。
- **单机演练 / 人机对弈**：
  - **皮卡鱼 (Pikafish NNUE)**：引入世界顶尖开源中国象棋神经网络引擎，原生支持 Apple Silicon、Linux 及 Windows，结合 NNUE 神经网络评估算法，提供极其强大的对弈体验。
  - **多档难度**：初级练手、棋摊好手、业余大师、特级大师等多难度档位，无论是新手测试绝杀还是高手攻防切磋皆可满足。
  - **传统启发式 AI**：轻量级评估引擎备选，支持即开即练。
- **本地双人同屏**：
  - 面对面同屏轮流出招。

## 技术栈

- **前端**：React 19 + TypeScript + Vite + Tailwind CSS + Canvas VFX + Lucide Icons + Canvas-Confetti
- **后端**：Node.js + Express 5 + Socket.IO + TypeScript (tsx)
- **音效**：Web Audio API 真实物理振荡合成

## 快速开始

### 安装依赖
```bash
pnpm install
```

### 启动开发环境
同时启动后端实时服务 (端口 3001) 与前端热重载服务 (端口 5173)：
```bash
pnpm dev
```
打开浏览器访问：`http://localhost:5173`

### 生产打包与运行
```bash
pnpm build
pnpm start
```
单服务直接在 `http://localhost:3001` 承载前端与 WebSocket 通信。
